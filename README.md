# ACME Corp - Internal Website

Company intranet and admin portal.

## Structure
- `/admin` - Admin panel (restricted)
- `/uploads` - File upload directory
- `/backups` - Backup storage

## Requirements
- PHP 8.x
- MySQL 8.x
- Apache 2.4

## Setup
Copy `config.example.php` to `config.php` and fill in your credentials.
Contact fong@acmecorp.internal for access.
